# 原始資料收納區 (Raw Sources)

這裡是你的**不可變事實來源庫（Source of Truth）**。

## 使用方式
你可以把任何想讓 Agent 學習、整理並編譯成繪本簡報的資料放進這裡：
- 複製貼上的網路教學文章（`.md` 或 `.txt`）
- 自己的學習筆記與踩坑紀錄
- 官方文件的特定段落
- 任何常見的 Git 終端機報錯紀錄

> **注意**：Agent 永遠只會「讀取」這裡的資料，絕不會修改或刪除原始來源檔案。
> 放置新文章後，只要告訴 Agent：「**請幫我 Ingest raw/ 裡的文章**」，Agent 就會自動提煉繪本隱喻、建立/更新 Wiki 頁面、並登記到目錄與日誌中！
