# Git 與 GitHub 的差別：隨身畫具箱 vs 雲端世界藝廊

初學者最常產生的誤解就是：「**我學了 Git 就一定要開 GitHub 嗎？**」或是「**GitHub 是不是就是 Git？**」
其實這兩者就像「**相機**」與「**Instagram**」的關係：一個是拿在手上的工具，另一個是大家分享作品的網路社群。

---

## 🎨 繪本隱喻 (Visual Metaphor)

1. **Git ＝ 畫家隨身攜帶的魔法畫具箱 🧰**
   - 誕生於 2005 年（由 Linux 之父 Linus Torvalds 所創）。
   - 它完全住在你的筆電裡，即使在沒有網路的荒島上，你依然可以用它來記錄作品的每次修改、存檔、開平行畫布。
   - 它是一個離線就能運作的單機工具。

2. **GitHub ＝ 飄浮在雲端上的全球萬國藝廊 🏛️☁️**
   - 它是世界上最巨大的 Git 作品代管平台。
   - 當你想要把隨身畫具箱裡的照片分享給朋友、或是和全世界的畫家一起合力完成一幅巨作時，你需要把作品上傳到 GitHub。
   - 藝廊提供很多好康：
     - **公開/私有展廳（Public / Private Repo）**：可以免費公開給全世界看，也可以鎖上門只給自己看。
     - **提取要求（Pull Request）**：邀請其他畫家幫你審查畫作、提出修改建議。
     - **問題追蹤（Issue）**：留言板，大家可以在上面許願新功能或回報畫布破洞。
     - **自動守護精靈（GitHub Actions）**：當你交卷時，自動幫你檢查格式並自動上架。

---

## 💡 核心觀念 (Core Concept)

- **Git 是引擎，GitHub 是展示舞台**：
  - 沒有 GitHub，Git 依然能在本機完整記錄版本。
  - GitHub 則是基於 Git 建立的雲端協作社群，讓開源專案（如 Linux Kernel、React、Vue）能被全球開發者共同打造。
- **履歷與作品集**：
  - GitHub 上的綠色格子（提交紀錄）與開源參與，就是現代工程師最真實且有力的「實戰作品集」。

## ⚡ 常用指令與咒語 (Key Commands)

```bash
# Git 本機名片設定（讓 GitHub 認得這是誰畫的）
git config --global user.name "你的GitHub帳號名稱"
git config --global user.email "你的註冊Email"

# 檢查目前名片設定
git config --list
```

## 🛟 新手容易踩的雷 (Gotchas & Traps)

> [!NOTE]
> **「我在電腦裡改了檔案並 commit 了，為什麼 GitHub 網頁上還是舊的？」**
> 
> **解答**：因為 Git 預設只把歷史記錄存放在你電腦的「本地倉庫」。要讓雲端藝廊也同步更新，你必須主動使用 `git push`（推送到雲端）把新作品送上去！
