# `git init` — 喚醒畫室記錄精靈

當你打開一個全新的空白資料夾時，電腦並不知道你想用版本控制來保護它。`git init` 就是那句點石成金的通關密語！

---

## 🎨 繪本隱喻 (Visual Metaphor)
> 在安靜的樹洞裡，你在地板上鋪了一張隱形的保護毯。這時，一位長著貓耳朵的「紀錄小精靈」從壁爐裡跳出來，揉揉眼睛說：「**主人您好！從今天起，這個房間裡的每一張畫稿，我都幫您看守著！**」

---

## 💡 核心觀念 (Core Concept)
- 在當前目錄下建立一個隱藏的 `.git` 資料夾。
- 這個 `.git` 檔案夾就是 Git 的大腦與時光相簿，負責存放所有歷史提交紀錄與分支指標。
- **只需要執行一次**：一個專案在最初建立時只要跑一次即可，不需要每次存檔都重新 init。

---

## ⚡ 常用指令與咒語 (Key Commands)

```bash
# 在目前所在目錄初始化 Git 倉庫
git init

# 或者直接建立一個新資料夾並在裡面初始化
git init my-awesome-project
```

---

## 🛟 新手容易踩的雷 (Gotchas & Traps)
- **千萬不要在「桌面」或「根目錄」下亂跑 `git init`！**
  - 如果在 `C:\Users\username` 或整個桌面執行 `git init`，Git 就會試圖監控你整台電腦的所有私人檔案，造成嚴重的混亂與卡頓。
  - **正確作法**：先為專案建一個獨立資料夾，用 `cd` 進去之後，再執行 `git init`。
