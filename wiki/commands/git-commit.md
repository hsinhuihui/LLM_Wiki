# `git commit` — 喀擦一聲！留下永久的時光快照

`git commit` 會將暫存區上的所有內容打包，生成一個具有唯一身分證號（SHA-1 Hash）的不可抹滅存檔點。

---

## 🎨 繪本隱喻 (Visual Metaphor)
> 戴著貝雷帽的小貓攝影師站在腳架前，對著展示台上的作品倒數：「三、二、一，笑一個！」
> 伴隨著清脆的「喀擦！」聲，一張邊緣泛著微光的拍立得照片滑出相機。你在照片下方的空白處用鉛筆端正地寫下這張照片的故事，然後小心翼翼地把它收進綠色的精裝時光相簿中。

---

## 💡 核心觀念 (Core Concept)
- 提交是本地倉庫的永久歷史紀錄。
- 每個 Commit 包含：檔案變更快照、作者、時間戳、以及這張相片的說明（Commit Message）。
- **良好的習慣**：一個 Commit 只做一件事，並用簡潔白話的文字記錄「這次做了什麼改動」。

---

## ⚡ 常用指令與咒語 (Key Commands)

```bash
# 最常用：直接在單行寫下提交訊息
git commit -m "feat: 完成首頁小貓主角導航列"

# 救命咒語：剛提交完發現少帶了一個檔案，或 Commit 訊息寫錯了想要改！
git commit --amend -m "feat: 修正首頁小貓導航列文字"
```

---

## 🛟 新手容易踩的雷 (Gotchas & Traps)
- **忘記加 `-m` 參數**：只打 `git commit` 會直接掉進 Vim 終端機純文字編輯器裡，讓新手嚇得不知道怎麼關掉！（**解法**：按 `Esc`，然後依序輸入 `:wq` 再按 `Enter` 即可存檔離開）。
