# `git add` — 請畫稿登上拍照展示台

`git add` 是將工作區（草稿桌）的修改，加入到暫存區（Staging Area）的重要咒語。

---

## 🎨 繪本隱喻 (Visual Metaphor)
> 桌上散落著鉛筆稿、水彩草圖和寫了一半的便條紙。你輕輕拍拍其中幾張畫好的圖，牽著它們的手走上相館中央鋪著紅天鵝絨的拍照台。其他還沒畫完的稿子，就繼續留在桌上曬太陽。

---

## 💡 核心觀念 (Core Concept)
- 決定「**哪些變更應該被包進下一次提交（commit）中**」。
- 支援單檔添加或批次全選。

---

## ⚡ 常用指令與咒語 (Key Commands)

```bash
# 只將特定檔案放上展示台
git add index.html

# 一口氣將當前目錄下「所有修改過與新建立的檔案」全部請上展示台
git add .
```

---

## 🛟 新手容易踩的雷 (Gotchas & Traps)
- **忘記加小數點 `.`**：`git add .` 的點代表「當前目錄所有內容」，少打那個點終端機會困惑報錯。
- **放上展示台後又偷偷改動**：記得要再跑一次 `git add`，展示台只會留下當下擺上去的模樣。
